## 做了什么（What）

本轮把平台的共享视觉基线收成了一套更成熟的金融产品风格，并按真实用户路径跑了前端烟测。

- 修改 `apps/api/src/quant_platform_api/static/theme.css`
  - 统一全站配色到更克制的金融风格：深色顶栏、冷灰背景、明确的卡片层级和更高的文字对比度
  - 强化共享组件样式：`topbar`、`hero`、`card`、`btn`、`result-box`、表格、列表、快捷入口、能力声明、导师/助手卡片
  - 给 hero 和卡片增加更明确的层次信号，减少原先过亮、原型感偏强的观感
- 重写 `apps/api/src/quant_platform_api/static/app.css`
  - 让首页/试用版工作台和其它页面使用统一视觉语言
  - 侧边栏改为深色研究台风格，主内容区和表单组件与主站保持一致
- 修改 `tests/test_static_assets.py`
  - 新增视觉基线断言，锁住本轮新的主题变量、暗色顶栏和首页样式骨架
- 真实浏览器烟测
  - 截图审查了 `workspace / strategy / backtests / replay / mentor / assistant`
  - 回归了登录、策略工坊、导师、助手、回测中心、复盘截图 OCR、复盘长文字识别等主要路径

## 为什么这样做（Why）

- 之前页面虽然功能已齐，但整体观感过亮、卡片同质化严重、导航和信息层级都偏“原型态”，不像成熟的面向大众的金融平台。
- 这轮没有只修单页，而是先收共享视觉基线，原因是：
  - 工作台、策略工坊、回测、复盘、导师、助手都在复用同一套结构
  - 先改共享层，才能让平台整体风格真正统一
- 没有引入新的前端框架或组件库，继续沿用现有 `FastAPI + 多页面 HTML + Vanilla JS + CSS` 体系，避免把任务从“UI 专业化”变成“前端重构”。
- 对异步模块的烟测以“任务能正常发起、状态能可见、结果链路不报错”为主，而不是要求短时间内所有长任务都同步完成，这符合当前平台的后台任务模式。

  - 更清晰的 hero / KPI / 明细区分层
  - 首页与内页风格一致
- 浏览器烟测结果：

  - `replay` 中等长度长文字识别正常
