  - 新增接口 `/api/v1/mentor/topics`、`/api/v1/mentor/ask`

- 给管理员后台补了真实错误观测能力：
  - 新增应用日志模型、表和仓储：`AppLogRecord` / `ApplicationLogORM` / `SQLAlchemyApplicationLogRepository`

- 在 `shared.js` 中接入前端自动报错上报：
  - API 非 2xx、网络失败、`window.error`、`unhandledrejection` 都会尝试上报
  - 管理员现在可以在后台直接看到真实用户使用中出现的前端/接口报错
- 更新了仓库内和仓库外接力文档，写入本轮新增的导师模块和应用日志后台能力

## 为什么这样做（Why）

- 用户要求继续按真人用户习惯优化 UI，并补一个能教新手理解交易和平台流程的导师模块；因此本轮没有引入外部 LLM，而是先用稳定的内置导师逻辑落一版可用能力，后续再替换模型层即可。
- 模块头部介绍区此前字号偏大、文案偏满，阅读节奏更像演示页而不是成熟应用平台，所以统一收紧到更接近产品化界面。
- “管理员需要看到用户使用时报错和日志”是实际运维必需能力，因此把这层做成真正的端到端链路：
  - 前端能报
  - 后端能记
  - 管理后台能看
- 前端错误上报放在 `shared.js`，是为了让所有模块页面自动继承，不必逐页重复埋点。
