# 工作简报：金融导师追问对话框

- **Agent**: codex
- **日期**: 2026-04-02 11:56
- **涉及模块**: `models.py`, `services.py`, `static/mentor.html`, `static/mentor.js`, `static/theme.css`, `tests/test_quant_platform_api.py`, `tests/test_static_assets.py`, `产品设计/AI量化交易平台_新环境恢复与Agent接力说明.md`

## 做了什么（What）

- 给金融导师补了真正可继续追问的对话框：
  - 页面新增“继续追问导师”区域
  - 新增对话记录展示区，保留用户和导师的往返消息
  - 新增追问输入框和按钮，首次回答后可继续提问
- 扩展 `MentorAskRequest`，增加 `conversation_history`
- 调整 `MentorService`：
  - 会根据历史问题和“再解释一下 / 举个例子 / 还是不懂”等追问词，沿着上一轮问题继续解释
  - 修正了分类优先级，避免“回测结果先看哪些指标”被误判成技术指标基础问题
- 补了导师页面和导师追问能力相关测试

## 为什么这样做（Why）

- 用户明确要求导师回答后还要能继续追问，否则单次答案对新手不够友好
- 继续追问不能只是再次发送独立问题，否则导师容易丢失上下文；因此把历史问题带进请求体，让服务端根据上下文继续解释
- 分类顺序单独修正，是因为“回测里先看哪些指标”这类问题同时包含“回测”和“指标”，按交易研究语义应该优先归入回测解读

## 结果（Result）

- 导师模块现在支持连续问答，不再是一次性静态建议
- 测试通过：
  - `python3 -m unittest tests.test_quant_platform_api.QuantPlatformApiTests.test_mentor_page_is_available_after_login tests.test_quant_platform_api.QuantPlatformApiTests.test_mentor_endpoints_return_topics_and_structured_answer tests.test_quant_platform_api.QuantPlatformApiTests.test_mentor_followup_uses_conversation_history_for_further_explanation`
  - `python3 -m unittest tests.test_static_assets`
- 已知限制：
  - 当前仍是规则驱动导师，不是真正多轮 LLM 对话
  - 历史上下文目前主要用于“继续解释”类型追问，还没有做更复杂的多轮记忆压缩
- 后续建议：
  - 如果后面接入正式 LLM，可直接沿用 `conversation_history` 这个接口结构
