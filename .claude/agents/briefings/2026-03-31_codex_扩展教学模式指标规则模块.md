## 为什么这样做（Why）

- 把“教学模式”做成后端能力而不是前端字符串替换
  - 这样 Python 代码和结构化 DSL 始终一致，注释只是额外解释层
- 指标库和术语库都做成持久化数据
  - 避免每次刷新页面都丢失
  - 为后续真正接大模型和更复杂的策略解释保留知识底座
- 传统指标采用默认折叠
  - 满足“先看标题、按需展开”的信息密度要求
- 回测历史改成固定高度滚动区
  - 解决历史记录越来越多时页面长度失控的问题

需要后续 agent 注意：

- 自定义指标目前仍是“规则模板生成”，不是真实 LLM 生成
- 术语库已经能影响策略解释，但还没有深入接入回测执行层
- 这是临时公网地址，不是正式部署
