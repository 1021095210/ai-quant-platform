## 为什么这样做（Why）

- 上一轮已经把“自然语言 / 结构化规格 / 平台硬校验”分开了，但用户仍然不够清楚：
  - DSL 是什么层
  - Python 是什么层
  - 哪一层才是后续保存和回测的真值来源
- 这轮把生成链路完整拆出来，是为了进一步收紧策略工坊的边界：
  - 结构化规格是真值层
  - 平台硬校验是规则层
  - DSL 是执行规格层
  - Python 只是派生表达层
- 这样后续继续接 AI 时，能避免“用户误以为 Python 才是真值”的问题。
