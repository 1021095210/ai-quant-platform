## 为什么这样做（Why）

- 之前外链环境显示 `llm_configured=false` 的根因不是模型本身不可用，而是：
  - 运行中的 `uvicorn` 没有读到任何 LLM 环境变量
  - `.env` 只是文件，没有自动加载
  - `healthz` 又只检查通用 `LLM_BASE_URL + LLM_API_KEY`
- 这会造成一个误导：实际上火山 profile 可以用，但健康检查仍显示没配置。
- 这轮把问题分成两层处理：
  - 运行时：让服务能自动读到本地 `.env`
  - 观测层：让 `healthz` 真正反映“是否存在可用 LLM profile”
