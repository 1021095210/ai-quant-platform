# 2026-04-09 Codex 工作简报：修复复盘长文字多日期批量解析

## 本轮完成

- 修复交易复盘“长文字智能识别”对多日期分组清单无反应的问题
- 解析逻辑从“单日期 + 一组代码”扩展为支持：
  - 多个 `YYYY-MM-DD` 日期块
  - 每个日期块下挂一组股票代码
  - 文末统一写“以上日期买入 / 买入方式 / 卖出方式”
- 扩展 A 股代码清洗：
  - `600501con9.SH` -> `600501.SH`
  - `002174.SZfinalsell` -> `002174.SZ`
  - 明显无效代码如 `000.SH` 自动忽略
- 扩展 ATR 卖出规则文本识别，支持：
  - `价格低于当日开盘价-0.5倍atr时卖出`

## 当前边界

- 当前仍按“同一段文字里的全局买卖规则”应用到所有日期块
- 还不支持“每个日期块内部各自不同的买卖规则”
- 大批量样本仍会真实补价，因此解析耗时会明显高于单笔文本

## 建议下一步

- 支持“每个日期块分别定义不同买卖规则”
- 对超大批量长文本解析补进度提示与异步化
- 增加更多脏代码格式和群聊记录格式的清洗规则
