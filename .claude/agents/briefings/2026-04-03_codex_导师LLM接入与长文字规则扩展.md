## 做了什么（What）

- 给金融导师接入了真实 AI 回答通道：
  - `MentorService` 现在读取 `Settings`
  - 支持 `LLM_*` 环境变量
  - 也支持回退读取 `OPENAI_BASE_URL / OPENAI_API_KEY / OPENAI_MODEL`
  - 当前兼容 OpenAI 兼容网关的 `stream=true` 流式返回，并把流式 chunk 拼成 JSON 结果
- 给导师补了更稳定的运行策略：
  - 返回结果新增 `answer_source` 与 `answer_mode_label`
  - 对 `429 / 5xx` 增加短重试，降低首次提问偶发退回兜底的概率
  - JSON 提取逻辑更宽容，允许从 fenced block 或带前后缀文本中截取对象
- 在无 LLM 时继续增强兜底能力：
  - 对“构造逻辑 / 为什么有效 / 更详细 / 怎么用”类追问，均线、MACD、RSI 不再机械重复上一轮，而是返回更深入解释
- 扩展了交易复盘长文字规则：
  - 支持 `YYYY/MM/DD`
  - 支持不带后缀的 6 位 A 股代码
  - 支持显式买入日期 / 卖出日期
  - 支持次日收盘价买入
  - 支持第 N 个交易日开盘 / 收盘价买入
  - 支持第 N 个交易日收盘价卖出
  - 支持百分比止盈 / 止损
  - 百分比规则未触发时，会明确说明按后续可用收盘价补全
- 前端导师页更新了脚本版本号，并在回答卡片里展示当前回答模式
- 同步更新了主接力文档、常见问题文件、金融导师模块文档、交易复盘模块文档，并镜像到仓库外接力目录

## 为什么这样做（Why）

- 用户明确指出导师回答“机械重复”，这说明只做模板化结构回答已经不够，必须补真实 AI 链路
- 当前环境实际上已经提供了 OpenAI 兼容网关，但原代码没有接入这些运行时配置，因此先把真实链路打通，再保留兜底
- 网关要求 `stream=true`，如果仍按普通 `chat/completions` JSON 响应写法，会导致“看起来接了 AI，实际一直回退”的假接入状态
- 长文字规则继续扩展，是为了让复盘真正能承接更自然的中文描述，而不是停留在少数几种硬编码表达
- 对止盈 / 止损未触发时给出明确说明，是为了避免“规则识别了，但结果解释仍然含糊”的问题
