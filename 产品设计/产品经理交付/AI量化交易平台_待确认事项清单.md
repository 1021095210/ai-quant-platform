# AI量化交易平台待确认事项清单

这份清单用于你后续和公司、资源部门、管理层讨论时快速聚焦需要拍板的问题。

## 1. 产品定位待确认

### 当前建议

- 定位为“研究与复盘平台”
- 当前不定位为“自动交易平台”
- 主要面向外部真实用户

### 当前已确认

- 短期主要对外给真实用户使用
- 公司希望把它作为可商业化的新产品方向

## 2. 用户优先级待确认

### 当前建议

- 面向多层级用户
- 双模式兼顾，略偏新手引导

### 当前已确认

- 金融导师偏教学，服务新手股民和不会编程的个人交易者
- 金融助手偏研究执行，服务有一定研究能力的高级用户

## 3. 数据投入待确认

### 当前建议

- A股先以内部 ClickHouse 为主
- 再补备用校验源
- 新闻和 OCR 逐步接入

### 需要确认

- 公司愿意投入到什么级别的数据采购
- 是先补 A股可信度，还是同步推进多市场

## 4. 商业化方向待确认

### 当前建议

- 先验证价值，再决定正式收费节奏

### 当前已确认

- 短期以个人用户为主
- 商业化方向预留：
  - 订阅会员制
  - 高级功能或成交复盘按次收费
  - 金融助手按 token 或高级额度收费
  - 后续企业版 / 团队版
- 免费版保留核心入口，但限制高成本能力额度
- 免费版成交复盘建议体验级额度为 `3-5 次 / 月`
- 免费版金融助手额度暂不写死，后续根据真实成本和转化测试定值
- 金融助手未来按 token 额度计费
- 成交复盘未来按“会员内含次数，超额按次”设计
- 会员版最核心的付费理由是：更多次数 / 更高额度
- 下一阶段产品优先先打磨交易复盘

## 5. 部署与合规边界待确认

### 当前建议

- 先做稳定可访问部署
- 保持研究和复盘定位

### 需要确认

- 是否要尽快上正式长期可访问环境
- 是否有公司内部安全、合规或数据使用要求需要提前纳入

## 6. 当前仍需继续确认的关键问题

1. 公司愿意投入到什么级别的数据、新闻、OCR 和部署资源
2. 企业版未来优先面向哪类客户
3. 免费版与会员版后续具体功能边界怎么划分
4. 金融助手最终的免费额度和会员额度应定在什么区间
5. 交易复盘与优化模块中“综合评分”的具体计算方式
6. 是否存在公司内部必须遵守的安全、合规、数据使用边界

## 7. 建议你优先向公司确认的三件事

1. 公司愿意优先投入哪类资源：数据、部署、OCR、新闻源
2. 下一阶段希望优先做“高可信研究平台”还是“多市场扩张”
3. 企业版是否作为今年需要预埋的方向
