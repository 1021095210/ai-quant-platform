# AI量化交易平台沟通口径：老板 / 设计 / 开发 / 测试

## 1. 和老板讲什么

### 重点

- 这不是单点工具，而是可商业化的新产品方向
- 当前价值不在于“页面多”，而在于已经形成学习、研究、回测、复盘闭环
- 第一阶段先验证用户是否持续回来使用，再验证付费意愿

### 一句话版本

这是一个面向外部真实用户的一站式学习量化、研究与复盘平台，当前最重要的是把可信度和留存做出来。

## 2. 和设计讲什么

### 重点

- 平台要同时服务新手和高级用户
- 体验上双模式兼顾，但略偏新手引导
- 首页负责吸引和分流，工作台负责中枢，导师负责新手引导
- 交易复盘是第一差异化功能，不能做得像普通后台表单

### 设计要重点解决的问题

- 新手第一次进来是否知道下一步做什么
- 高级用户是否能快速进入研究状态
- 多模块切换是否自然
- 关键按钮和下一步动作是否足够明确

## 3. 和开发讲什么

### 重点

- 当前主路径是：`金融导师 -> 策略工坊 -> 回测中心 -> 交易复盘`
- 当前主指标是 `7日留存`
- 第一差异点是 `真实成交复盘`
- 所有高可信能力优先级高于新页面扩张

### 开发规则

- 数据优先内部数据中心
- 回测必须展示执行约束和数据来源
- 导师与助手后续必须走证据链
- 免费版和会员版要预留额度结构

## 4. 和测试讲什么

### 重点

- 不只测页面能不能开，还要测用户主路径是否能跑通
- 不只测成功流，还要测额度、异常、权限和来源展示

### 当前测试重点

- 登录和用户隔离
- 导师到策略到回测到复盘主链路
- 交易复盘识别与来源记录
- 数据来源、执行约束、快照摘要展示
- 免费额度与后续会员结构预留逻辑
