# AI量化交易平台功能清单与业务规则

## 1. 功能清单

### A. 入口与账户

- 首页
- 登录
- 注册
- 用户工作台
- 管理员后台

### B. 研究主链路

- 策略工坊
- 回测中心
- 交易复盘

### C. 辅助能力

- 指标设置
- 规则模块
- 金融导师
- 金融助手

## 2. 当前主路径

当前定义的第一主路径为：

`金融导师 -> 策略工坊 -> 回测中心 -> 交易复盘`

适用原因：

- 新手更容易进入
- 同时兼顾研究与复盘闭环

### 入口分工规则

- 首页：负责吸引、分流和介绍平台价值
- 工作台：负责登录后的统一中枢
- 金融导师：负责新手教学、平台使用指导和量化入门引导

## 3. 核心业务规则

### 3.1 平台定位规则

- 当前平台是研究与复盘平台
- 当前不承诺自动交易执行

### 3.2 数据规则

- 平台优先读内部数据中心
- 当前优先 `ADS / DWD`
- `ODS` 只做原始回查、补数和审计

### 3.3 回测规则

- 回测必须展示数据来源
- 回测必须展示执行约束
- 缺失的重要规则不能假装已支持

### 3.4 复盘规则

- 成交复盘是平台核心差异化功能
- 成交复盘当前最核心的价值是：看出问题并给出优化建议
- 成交复盘与优化是下一阶段优先打磨模块
- 默认先展示精简结论，再展示亏损特征
- 优化目标分版本必须同时展示收益曲线和成交买卖记录，方便用户逐条对照真实交易确认
- 旧新参数对比、指标条件替换、目标分版本对比三者同时保留，不互相替代
- OCR 和自动识别结果必须允许人工确认
- 自动补价必须记录补价来源

### 3.5 导师与助手规则

- 金融导师偏教学
- 金融导师负责纯新股民、小白用户的金融知识教导，以及所有用户的平台使用指导和量化指导
- 金融助手偏研究执行
- 后续都要逐步升级为引用式回答

### 3.6 商业规则

- 当前阶段先不收费
- 产品结构上预留免费版 / 会员版
- 后续可能对高级功能、复盘次数、助手额度做收费设计
- 免费版默认保留全部核心功能入口，但限制高成本能力额度
- 免费体验的核心原则不是只突出某一个模块，而是让不同用户都能在自己最感兴趣的模块里感知到价值
- 当前建议：
  - 成交复盘：`3-5 次 / 月`
  - 金融助手：按 token 额度设计，能完整体验 `1-2 次` 高质量研究流程的额度
- 免费版超出额度后：
  - 可升级会员
  - 也可单独购买额外额度
- 会员版：
  - 提升复盘次数和金融助手额度
  - 会员额度超上限后，继续按额度收费
- 会员版最核心的付费理由是：更多次数 / 更高额度
- 企业版保留为未来方向，不纳入当前 MVP 范围

## 4. 后续收费候选点

- 会员订阅
- 成交复盘按次收费
- 金融助手额度收费
- 企业定制服务
