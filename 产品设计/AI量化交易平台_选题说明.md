# AI 量化交易平台选题说明

## 一句话定义

我要做一个 `AI 量化交易研究与复盘平台`，帮助 `具备交易经验但不会编程或量化开发成本过高的交易者` 解决 `策略难以快速验证、交易复盘依赖主观经验、无法系统提升胜率` 的问题。

## 目标用户

- 主用户：有一定交易经验的个人交易者、半职业量化交易者、交易团队研究员
- 使用频率：高频研究场景为每日使用，复盘场景为每周或每月使用
- 典型场景：
  - 有交易想法，但不会写策略代码，想用自然语言直接生成策略并回测
  - 已有一批历史交割单，想找出失败与成功交易的共同特征
  - 想把“量价关系 + 均线状态 + 自定义指标”变成可验证规则

## 核心问题

- 当前痛点：
  - 传统量化平台门槛高，必须学脚本或写代码
  - 交割单复盘通常停留在主观总结，缺少数据化归因
  - 很多交易者知道自己“常亏在哪”，但无法量化验证改进规则
- 现有替代方案：
  - 使用 TradingView、聚宽、Backtrader 等工具自行写策略
  - 手工在 Excel 中复盘交割单
  - 凭经验记录“这笔单为什么亏了”，但缺少系统验证
- 为什么值得现在做：
  - LLM 可以把自然语言转为结构化策略
  - 指标计算和回测能力可以让“主观经验”转成可验证规则
  - 交割单复盘和策略研究放到同一平台里，能形成持续优化闭环

## MVP 范围

### Must

- [x] 用户通过自然语言生成结构化量化策略
- [x] 平台支持内置技术指标与受限表达式形式的自定义指标
- [x] 策略可在历史行情上回测，并展示核心指标与收益曲线
- [x] 用户可上传交割单 CSV/XLSX，系统自动解析交易记录
- [x] 平台自动分析成功/失败交易特征，并给出策略改进建议

### Should

- [x] 支持参数优化，输出最优参数组合及参数敏感性结果
- [x] 支持用户指定“量价 + 均线”等复盘维度进行定向分析
- [x] 支持从复盘建议一键生成策略过滤条件并重新回测

### Could

- [x] 支持策略版本对比
- [x] 支持导出复盘报告
- [x] 支持指标模板收藏

### Won't

- [x] 本周不做实盘下单和券商接入
- [x] 本周不做实时行情订阅
- [x] 本周不做多用户团队协作权限体系

## 不做清单

- 不做自动交易执行
- 不做真实资金账户管理
- 不做生产级风控引擎和合规审计后台

## 为什么值得做

- 用户价值：把“会交易但不会量化”的人群拉进可验证的策略研究流程
- 演示价值：自然语言生成策略、回测结果、交割单复盘三段演示链路非常完整
- 学习价值：天然覆盖 LLM、策略 DSL、指标计算、回测、可视化、数据解析和 AI 复盘

## 演示闭环

- 演示入口：进入策略研究页，输入自然语言策略描述
- 核心操作：
  - 生成策略草案
  - 选择或创建指标
  - 运行回测并查看结果
  - 上传交割单并运行复盘分析
  - 将复盘建议转为策略过滤条件重新回测
- 成功结果：
  - 系统生成结构化策略
  - 回测页面展示收益曲线、回撤、胜率、盈亏比
  - 复盘页面展示亏损/盈利交易的共同特征和优化建议

## AI 参与点

- AI 用于：
  - 将自然语言解析为策略 DSL
  - 解释策略逻辑和提示歧义
  - 生成交割单复盘结论与改进建议
- 预期帮助：
  - 降低量化研究门槛
  - 缩短从想法到回测的链路
  - 帮助交易者把主观经验沉淀为规则
- 需要重点验证的地方：
  - AI 输出策略不能直接执行，必须转为受限结构化 DSL 并经过校验
  - 复盘结论必须基于可计算特征，不能只靠 LLM 自由发挥
