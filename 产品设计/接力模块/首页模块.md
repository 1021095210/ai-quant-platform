# 首页模块

## 当前定位

- 路由：`/`
- 角色：公开入口页
- 原则：首页只承担平台入口和品牌表达，不承担研究状态展示

## 当前已实现

- 品牌标题已统一为“量化研究平台”
- 已移除公开展示的默认测试账号
- 已移除“能力状态”区块
- 公开访问下可跳转登录、注册和主要模块介绍

## 主要文件

- `apps/api/src/quant_platform_api/static/dashboard.html`
- `apps/api/src/quant_platform_api/static/theme.css`
- `apps/api/src/quant_platform_api/main.py`

## 当前设计约束

- 首页语言要更像成熟 Web 应用平台，不能写成演示页口吻
- 不要把登录后的研究信息堆回首页
- 平台状态、研究状态、任务状态统一放到登录后的工作台

## 下一步关注

- 继续优化平台入口文案
- 维持与登录后工作台之间的边界清晰
