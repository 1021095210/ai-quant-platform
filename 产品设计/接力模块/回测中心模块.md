# 回测中心模块

## 当前定位

- 路由：`/backtests`
- 角色：发起回测、阅读结果、做实验对比

## 当前已实现

- 已新增“本次回测支持范围”区块：
  - 会按所选策略版本显示当前市场和周期的真实回测支持状态
  - 对不支持的市场会直接禁用“运行回测”按钮
  - 对 A股混合周期 / 非日线策略会明确提示“仅支持日线兼容层回测”
- 已新增“市场支持状态”矩阵：
  - 明确显示各市场当前是“可真实回测”还是“仅支持策略语义 / 规则研究”
- 回测配置对象化
- 数据快照摘要
- 执行可信度说明
- 最小仓位与风控模型
- 回测历史列表支持删除
- 历史列表与左侧新回测面板高度联动，超出再滚动
- 支持 2 到 4 条回测记录对比
- 详情区顺序已调整为：
  - 核心指标
  - 回测曲线
  - 成交明细
  - 回测配置摘要
  - 执行可信度说明
  - 数据快照摘要
  - 策略 Python
- 专业术语已补说明气泡：
  - 复权模式
  - 手续费
  - 滑点
  - 成交方式
  - 盘中撮合策略
  - 交易日历
  - 时区
  - 预热 Bar 数
  - 最大回撤保护
  - 最大持有 Bar 数
  - 市场成交约束

## 当前设计约束

- 页面文案不要直接暴露 `t_plus_one`、`qfq`、`raw` 这类内部英文值
- 新手先看结果和曲线，再看配置摘要和执行边界
- 同日是否可卖、盘中撮合等规则要继续下沉到执行逻辑，而不只是解释文案
- 不支持真实回测的市场必须直接阻止提交，而不是只在页面上模糊提示
