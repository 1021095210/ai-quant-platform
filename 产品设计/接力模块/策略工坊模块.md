# 策略工坊模块

## 当前定位

- 路由：`/strategy`
- 角色：把自然语言交易想法转成结构化策略与 Python 策略骨架

## 当前已实现

- 支持 A股 / 美股 / 加密货币 / 伦敦金
- 支持混合周期：
  - 1分钟 / 5分钟 / 15分钟 / 30分钟 / 1小时 / 4小时 / 日线 / 周线 / 月线
- 已新增“当前能力声明”区块：
  - 会按当前市场与周期显示“可描述 / 可真实回测 / 数据链路”状态
  - A股日线单周期会显示“可直接运行真实日线回测”
  - A股混合周期 / 非日线会显示“仅支持日线兼容层回测”
  - 美股 / 加密货币 / 伦敦金会明确显示“当前暂不开放真实回测”
- 已新增“市场支持状态”矩阵：
  - 明确区分“可生成与保存策略语义”和“可真实执行回测”
- 顶部支持直接编辑：
  - 策略名称
  - 版本标签
- 已新增“系统理解结果”与“待补充与风险提示”区块：
  - 会先展示系统理解到的：
    - 市场
    - 周期
    - 入场条件
    - 离场条件
    - 数据依赖
    - 执行假设
  - 会单独展示：
    - 待补充问题
    - 不支持项
    - 未来函数风险
- 已新增策略生成状态体系：
  - `ready`
  - `semantic_only`
  - `needs_confirmation`
  - `rejected`
- `保存项目` 和 `去回测中心` 当前不再只看“有没有生成代码”，还会受生成状态控制：
  - `ready` 可保存并继续
  - `semantic_only` 可保存，但真实执行受平台边界限制
  - `needs_confirmation` 不允许直接保存正式版本
  - `rejected` 不允许继续保存 / 回测
- 成功生成 Python 策略后：
  - 只有满足生成状态门槛时，后续动作按钮才会点亮
- 已打通“待补充问题 -> 二次确认 -> 重新理解”第一阶段：
  - 用户可直接在页面里填写每条待补充问题的补充说明
  - 可点击“应用补充并重新理解”重新进入生成链路
  - 当前已支持把补充说明写回：
    - 量能阈值
    - 不追高定义
    - 确认规则
    - 市场环境条件
    - 仓位规则
- 已新增“自然语言 -> 结构化规格 -> 平台硬校验”并排预览第一阶段：
  - 页面会单独展示：
    - 自然语言输入
    - 结构化规格
    - 平台硬校验清单
  - 结构化规格会明确展示：
    - 市场
    - 周期
    - 规则数量
    - 仓位
    - 执行假设
    - 待补充项
  - 平台硬校验当前会明确区分：
    - 市场与回测支持范围
    - 周期与执行兼容范围
    - 模糊条件完整性
    - 未来函数风险
    - 平台不支持的数据依赖
    - 当前是否具备正式策略生成资格
- 已新增“生成链路对照”视图：
  - 会把策略生成拆成：
    - 自然语言策略想法
    - 结构化策略规格
    - 平台硬校验
    - DSL / 结构化执行规格
    - Python 策略代码
  - 用途是让用户清楚知道：
    - 哪一层是真值层
    - 哪一层是平台规则判断
    - 哪一层只是派生代码结果
- 支持策略项目保存和版本管理

## 当前设计约束

- 用户可编辑的是“策略名称”和“版本标签”，不是系统内部 `version_id`
- 上一步完成后，下一步按钮必须显式点亮
- 混合周期 DSL 可以先保留语义层，即使执行层仍按 `backtest_timeframe`
- 多市场与多周期能力必须先声明边界，不能继续让用户误以为所有市场都已开放真实回测
- 策略工坊后续必须坚持：
  - 先“自然语言 -> 结构化策略规格”
  - 再做平台硬校验和用户确认
  - 最后才生成 DSL / Python
- 模糊条件、缺参数、未来函数风险和平台不支持项，不允许被系统悄悄补全后直接生成最终策略
- 当前“结构化规格”和“平台硬校验”是真值与规则层，不能让 AI 直接覆盖或跳过
  - 当前“生成链路对照”已经明确：
  - 结构化规格是真值层
  - 平台硬校验是规则层
  - Python 代码只是派生层，不应反向作为真值来源
- 已新增“字段级对照解释”视图：
  - 会把用户表达映射到：
    - 结构化规格字段
    - DSL 路径
    - Python 代码中的职责位置
  - 当前已覆盖：
    - 市场范围
    - 主执行周期
    - 入场规则
    - 观察层上下文
    - 离场与风控
    - 仓位规则
    - 正式生成门槛
- 未来函数风险规则当前已继续扩展：
  - 不只拦“当日最高价 / 最低价”
  - 也会继续拦：
    - 当日收盘价 / 今日收盘价直接参与当日盘中决策
    - 收盘前使用收盘价确认
