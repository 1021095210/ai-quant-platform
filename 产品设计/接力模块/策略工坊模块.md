# 策略工坊模块

## 当前定位

- 路由：`/strategy`
- 角色：把自然语言交易想法转成结构化策略与 Python 策略骨架

## 当前已实现

- 支持 A股 / 美股 / 加密货币 / 伦敦金
- 支持混合周期：
  - 1分钟 / 5分钟 / 15分钟 / 30分钟 / 1小时 / 4小时 / 日线 / 周线 / 月线
- 顶部支持直接编辑：
  - 策略名称
  - 版本标签
- 成功生成 Python 策略后：
  - `保存项目` 按钮点亮
  - `去回测中心` 按钮点亮
- 支持策略项目保存和版本管理

## 主要文件

- `apps/api/src/quant_platform_api/static/strategy.html`
- `apps/api/src/quant_platform_api/static/strategy.js`
- `apps/api/src/quant_platform_api/main.py`
- `apps/api/src/quant_platform_api/services.py`

## 当前设计约束

- 用户可编辑的是“策略名称”和“版本标签”，不是系统内部 `version_id`
- 上一步完成后，下一步按钮必须显式点亮
- 混合周期 DSL 可以先保留语义层，即使执行层仍按 `backtest_timeframe`

- 更真实的多周期执行层
