# 策略工坊模块

## 当前定位

- 路由：`/strategy`
- 角色：把自然语言交易想法转成结构化策略与 Python 策略骨架

## 当前已实现

- 支持 A股 / 美股 / 加密货币 / 伦敦金
- 支持混合周期：
  - 1分钟 / 5分钟 / 15分钟 / 30分钟 / 1小时 / 4小时 / 日线 / 周线 / 月线
- 已新增“当前能力声明”区块：
  - 会按当前市场与周期显示“可描述 / 可真实回测 / 数据链路”状态
  - A股日线单周期会显示“可直接运行真实日线回测”
  - A股混合周期 / 非日线会显示“仅支持日线兼容层回测”
  - 美股 / 加密货币 / 伦敦金会明确显示“当前暂不开放真实回测”
- 已新增“市场支持状态”矩阵：
  - 明确区分“可生成与保存策略语义”和“可真实执行回测”
- 顶部支持直接编辑：
  - 策略名称
  - 版本标签
- 成功生成 Python 策略后：
  - `保存项目` 按钮点亮
  - `去回测中心` 按钮点亮
- 支持策略项目保存和版本管理

## 当前设计约束

- 用户可编辑的是“策略名称”和“版本标签”，不是系统内部 `version_id`
- 上一步完成后，下一步按钮必须显式点亮
- 混合周期 DSL 可以先保留语义层，即使执行层仍按 `backtest_timeframe`
- 多市场与多周期能力必须先声明边界，不能继续让用户误以为所有市场都已开放真实回测

## 下一步关注

- 更强的版本说明与保存提示
- 更真实的多周期执行层
