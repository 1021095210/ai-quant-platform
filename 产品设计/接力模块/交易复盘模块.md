# 交易复盘模块

## 当前定位

- 路由：`/replay`
- 角色：把真实交易样本转成可复用的改进建议

## 当前已实现

- 支持三种数据来源：
  - CSV 导入
  - 成交截图
  - 手动录入
- 上传方式当前已改成“按钮切换 + 单一模式内容区”：
  - 点击 `CSV 导入` 时，只显示 CSV 文件上传与直接粘贴 CSV
  - 点击 `成交截图` 时，只显示截图识别与截图登记所需字段
  - 点击 `手动录入` 时，只显示手动补录表单与手动记录列表
- 上传方式区当前已补更明确的模式引导：
  - 当前方式标题
  - 适用场景说明
  - 建议顺序步骤提示
  - 选中方式的强化视觉态
- 手动录入当前已拆成两条子流程：
  - 长文字智能识别
  - 逐笔手动补录
- 长文字智能识别当前支持：
  - 从整段文字里识别 `YYYY-MM-DD`
  - 也可识别 `YYYY/MM/DD`
  - 识别一组 A股代码，如 `603590.SH, 002225.SZ`
  - 也可识别不带交易所后缀的 6 位 A股代码，如 `603590, 002225`
  - 识别买入规则：
    - 当日开盘价买入
    - 当日收盘价买入
    - 次日开盘价买入
    - 次日收盘价买入
    - 第 N 个交易日开盘价买入
    - 第 N 个交易日收盘价买入
    - 显式买入价
  - 识别卖出规则：
    - 当日收盘价卖出
    - 次日收盘价卖出
    - 第 N 个交易日收盘价卖出
    - 最低价低于“当日开盘价 - N 倍 ATR”时卖出
    - 上涨 N% 止盈卖出
    - 下跌 N% 止损卖出
    - 显式卖出价
  - 识别显式买入日期 / 卖出日期
  - 基于真实日线行情自动补全：
    - 买入价
    - 卖出价
    - 盈亏
  - 自动补价来源当前会写入记录说明，便于确认是平台内部哪条数据链路补全
- 当百分比止盈 / 止损在当前数据范围内未触发时，当前也会明确说明“未触发阈值，已按后续可用收盘价补全”，不再退回含糊说明
- 智能识别出的记录当前会直接加入手动记录列表，用户确认后再统一提交复盘
- 成交截图当前已补 `OCR 第一阶段`：
  - 可从截图中识别日期
  - 可识别 A股代码和部分纯数字代码
  - 可推断方向和默认入场时间
  - 可把识别到的独立盈亏数字自动回填
  - 用户可先点“智能识别截图内容”，再人工修正后提交
- 上传并解析完成后，`运行 AI 复盘` 按钮会点亮
- A股场景下不再给出不合理的“建议做空”
- 方向文案已按市场能力改成明确中文
- 单方向样本会输出单方向总结和更具体的规则建议
- 2026-04-09 已完成交易复盘结果结构升级第一阶段：
  - 后端当前不再只返回简单总结和建议规则
  - 当前会额外返回：
    - `concise_summary`
    - `overview`
    - `loss_features`
    - `profit_features`
    - `objective_versions`
    - `parameter_changes`
    - `condition_replacements`
    - `trade_records`
  - 当前默认主目标固定为 `夏普最大`
  - 当前每个目标版本已经升级为“基于已上传真实样本的筛选回放结果”：
    - 每个目标版本都会返回自己的 `metrics`
    - 每个目标版本都会返回自己的收益曲线
    - 每个目标版本都会返回自己的成交记录
    - 当前同时保留 `baseline_metrics` 作为原样本对照
  - 当前这些版本仍然不是“基于行情重新回测”的优化引擎结果，而是基于真实成交样本做确定性筛选回放，用于诚实对照确认
- `/replay` 页面当前已升级为多区块结果展示：
  - 精简结论
  - 复盘概览
  - 亏损特征
  - 盈利特征
  - 优化目标分版本
  - 旧新参数对比
  - 指标条件替换
  - 可回写规则建议
  - 当前样本成交记录
- 当前目标版本切换第一阶段已可用：
  - 默认选中 `夏普最大`
  - 可切换不同目标版本查看对应建议
  - 当前目标版本详情会展示：
    - 当前版本 vs 原样本 的关键指标对比
    - 当前版本收益曲线
    - 当前版本成交记录
  - 每个版本都会展示收益曲线和 5-10 笔成交记录
  - 成交记录默认展示买入价、卖出价、持仓时长和盈亏比例
- 2026-04-09 已把复盘分析配置接进主链路：
  - 页面当前已新增“分析配置”区：
    - 日线回看窗口
    - 分钟级观察窗口
    - 市场环境复盘
    - 自动触发环境复盘
    - 分钟级特征
    - 基本面复盘
  - 后端当前会把这些配置原样写入 `overview.analysis_scope`
  - A股样本在启用日线窗口后，当前会基于平台内部日线数据做第一阶段上下文特征提取：
    - 量比
    - 入场前窗口涨幅
    - 是否站上 5 日线
    - 趋势 / 震荡环境
  - 这些日线上下文特征当前已经会进入亏损特征 / 盈利特征提取
  - 分钟级特征和基本面复盘当前已进入真实数据接口层：
    - 分钟级特征会优先尝试读取内部 ClickHouse `1min` 数据
    - 基本面复盘会优先尝试读取内部 ClickHouse `dwd_mkt_daily_basic`
  - 分钟级特征当前已从基础涨跌/波动扩展到更细的盘中节奏：
    - 前 15 分钟涨跌幅
    - 末 15 分钟涨跌幅
    - 阳线占比
    - 收盘在窗口区间中的位置
    - 盘中高点回吐幅度
  - 基本面复盘当前已从基础估值 / 换手扩展到质量与成长因子：
    - PE(TTM)
    - PB
    - 换手率
    - ROE
    - 毛利率
    - 营收增速
    - 资产负债率
  - `objective_versions` 当前已接入 `日线 + 分钟级 + 基本面` 上下文评分：
    - 不再只按盈亏、方向和持有时间做样本筛选
    - 当前会综合：
      - 趋势 / 均线位置
      - 短期涨幅 / 量比
      - 前 15 分钟热度 / 收盘位置 / 回吐
      - PE / ROE / 毛利率 / 营收增速 / 资产负债率
  - A股样本当前已开始优先尝试“真实日线行情重放”：
    - 有真实内部日线时，目标版本会基于真实日线按过滤和持有规则重算
    - 没有真实数据时，才回退到“上下文评分的样本筛选回放”
  - A股日线重放当前已进入“小范围参数搜索”第一阶段：
    - 当前会围绕止损、止盈、最大持有 Bar 数、短期涨幅过滤、量能过滤、分钟结构过滤、基本面质量过滤生成有限候选版本
    - 当前会按目标函数在候选版本里选择当前最优补丁，并返回：
      - `selected_patch`
      - `search_summary`
      - `simulation_mode = market_rerun_optimized`
  - 分钟级真实重放当前已进入第一阶段：
    - 当 A股样本存在真实 `1min` 数据时，入场会优先按分钟线对齐实际入场时间和价格
    - 出场当前已优先支持：
      - 分钟级止损触发
      - 分钟级止盈触发
    - 如果同一根分钟 K 同时触发止盈和止损，当前会按保守口径优先记为止损触发
    - 当前分钟级真实重放第一阶段主要解决“分钟级入场对齐 + 分钟级止损 / 止盈触发时间和价格”问题
    - 如果当前环境没有真实 `1min` 数据，仍会诚实回退到日线近似止损判断
    - 当前分钟级结果已经会进入目标版本指标：
      - `minute_entry_aligned_count`
      - `minute_exit_triggered_count`
    - 这意味着分钟级结果已经开始进入版本比较，不再只是辅助说明
  - 上下文特征当前也已进入规则建议生成：
    - 盘中过热过滤
    - 分钟结构确认
    - 短期过热过滤
    - 趋势环境过滤
    - 基本面质量过滤
  - 如果当前环境没有真实内部数据，这两块会明确标成“当前无真实数据可用”，不会用 demo 数据伪装
  - `analysis_scope.labels` 当前会同时反映：
    - 用户本次请求了哪些分析维度
    - 这些维度当前的真实可用状态

## 当前设计约束

- 面向新手用户，按钮亮起状态必须明确反映下一步
- 不要把三种上传方式的全部表单同时摊在一个区域里
- 当前方式必须显式告诉用户“你正在用哪一种上传方式”和“下一步该做什么”
- 手动模式内部也要继续维持“智能识别”和“逐笔补录”的清晰分工，不能重新混成无结构的大表单
- A股现货默认按单向买入后卖出理解
- 自动补价、规则识别和盈亏推导，默认优先使用平台内部 ClickHouse / 平台数据中心，不应直接以原始外部接口结果作为用户侧真值
- 截图 OCR 目前还是第一阶段，识别后必须允许用户人工确认和改写，不能直接静默入库
