# 金融导师模块

## 当前定位

- 路由：`/mentor`
- 角色：帮助新手理解交易概念、技术指标和平台使用顺序

## 当前已实现

- 提供导师问题卡片
- 支持首次提问
- 支持继续追问
- 返回结构化内容：
  - 导师判断
  - 为什么重要
  - 建议下一步
  - 相关概念
  - 相关模块入口
- 已按市场边界区分 A股和可做空市场的制度解释

## 主要文件

- `apps/api/src/quant_platform_api/static/mentor.html`
- `apps/api/src/quant_platform_api/static/mentor.js`
- `apps/api/src/quant_platform_api/main.py`
- `apps/api/src/quant_platform_api/services.py`

## 当前设计约束

- 导师必须支持追问，不是一次性静态回答
- 新手问题要用明确中文解释，不要直接抛英文术语
- 导师页前端曾出现过缓存和脚本语法问题，后续改动必须：
  - 跑静态资源测试
  - 验证 `/api/v1/mentor/topics`
  - 验证首次提问和追问

## 下一步关注

- 新手版 / 专业版回答层次
- 与当前页面上下文联动
- 未来接正式 LLM Agent
