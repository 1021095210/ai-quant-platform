# 金融导师模块

## 当前定位

- 路由：`/mentor`
- 角色：帮助新手理解交易概念、技术指标和平台使用顺序

## 当前已实现

- 提供导师问题卡片
- 支持首次提问
- 支持继续追问
- 当前已新增后台异步问答模式：
  - 较长回答会转入后台生成
  - 用户可以先切到其他模块继续使用
  - 完成或失败后会弹出小消息提醒
  - 输入框上方会显示就近状态提示，不再只依赖页面顶部横幅
- 当前已支持两层回答链路：
  - 已配置 LLM 时，走真实 AI 多轮回答
  - 未配置 LLM 时，走平台兜底导师逻辑
- 返回结构化内容：
  - 导师判断
  - 为什么重要
  - 建议下一步
  - 相关概念
  - 相关模块入口
- 已按市场边界区分 A股和可做空市场的制度解释
- 当前导师回答结果会显式展示：
  - `AI 实时回答`
  - `平台导师兜底`
- 当前已加强“指标基础”类追问的兜底解释：
  - 会进一步解释均线、MACD、RSI 的构造逻辑
  - 会解释为什么有效
  - 会解释常见误用和实际使用顺序
- 当前环境下已兼容 OpenAI 兼容网关：
  - 可读取 `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL_MENTOR`
  - 也可回退读取 `OPENAI_BASE_URL / OPENAI_API_KEY / OPENAI_MODEL`
  - 当前网关要求 `stream=true`，后端已补流式解析
- 当前页面已新增 `模型选择`：
  - 统一从 `/api/v1/platform/llm-profiles` 读取可用模型配置
  - 用户可自主选择：
    - 模块默认模型
    - 导师模型
    - 其他当前已启用的 DeepSeek / 火山方舟配置
  - 当前火山方舟默认候选模型约定为：
    - `deepseek-v3-2-251201`
  - 如果显式选择的模型当前不可用，系统会诚实回退到模块默认模型

## 当前设计约束

- 导师必须支持追问，不是一次性静态回答
- 新手问题要用明确中文解释，不要直接抛英文术语
- 如果用户在追问里要求“更详细 / 构造逻辑 / 为什么有效”，回答不能机械重复上一轮
- 模型选择只能影响“回答生成层”，不能改变事实真值来源
- 导师页前端曾出现过缓存和脚本语法问题，后续改动必须：
  - 跑静态资源测试
  - 验证 `/api/v1/mentor/topics`
  - 验证首次提问和追问
