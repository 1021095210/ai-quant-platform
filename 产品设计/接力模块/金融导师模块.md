# 金融导师模块

## 当前定位

- 路由：`/mentor`
- 角色：帮助新手理解交易概念、技术指标和平台使用顺序

## 当前已实现

- 提供导师问题卡片
- 支持首次提问
- 支持继续追问
- 当前已支持两层回答链路：
  - 已配置 LLM 时，走真实 AI 多轮回答
  - 未配置 LLM 时，走平台兜底导师逻辑
- 返回结构化内容：
  - 导师判断
  - 为什么重要
  - 建议下一步
  - 相关概念
  - 相关模块入口
- 已按市场边界区分 A股和可做空市场的制度解释
- 当前导师回答结果会显式展示：
  - `AI 实时回答`
  - `平台导师兜底`
- 当前已加强“指标基础”类追问的兜底解释：
  - 会进一步解释均线、MACD、RSI 的构造逻辑
  - 会解释为什么有效
  - 会解释常见误用和实际使用顺序
- 当前环境下已兼容 OpenAI 兼容网关：
  - 可读取 `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL_MENTOR`
  - 也可回退读取 `OPENAI_BASE_URL / OPENAI_API_KEY / OPENAI_MODEL`
  - 当前网关要求 `stream=true`，后端已补流式解析

## 当前设计约束

- 导师必须支持追问，不是一次性静态回答
- 新手问题要用明确中文解释，不要直接抛英文术语
- 如果用户在追问里要求“更详细 / 构造逻辑 / 为什么有效”，回答不能机械重复上一轮
- 导师页前端曾出现过缓存和脚本语法问题，后续改动必须：
  - 跑静态资源测试
  - 验证 `/api/v1/mentor/topics`
  - 验证首次提问和追问

## 下一步关注

- 与当前页面上下文联动
- 导师对当前页面数据的理解，例如直接解释当前回测结果或当前策略条件
