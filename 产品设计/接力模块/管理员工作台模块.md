# 管理员工作台模块

## 当前定位

- 路由：`/admin`
- 角色：平台治理与运维后台

## 当前已实现

- 仅管理员可访问
- 可查看用户总数、管理员数、停用账户数、活动会话、项目数、回测数、运行中任务
- 可查看角色分布、任务状态分布、任务类型分布、最近任务、数据快照状态、治理建议
- 已支持用户角色切换
- 已支持用户停用 / 恢复
- 已支持重置用户密码并清理旧会话
- 已支持查看登录安全事件、管理员审计日志、应用日志

## 当前设计约束

- 管理后台要按成熟平台后台思路继续演进，不是普通工作台换皮
- 最后一个管理员不能被降权或停用
- 管理员后台需要持续沉淀：
  - 平台日志
  - 用户报错
  - 安全事件
  - 审计痕迹

## 下一步关注

- 日志筛选与错误分类
- 任务重试 / 终止 / 检索
- 更完整的用户治理能力
