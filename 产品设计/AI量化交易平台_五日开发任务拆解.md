# AI 量化交易平台五日开发任务拆解

## 拆解原则

- 每个任务尽量控制在 2 到 4 小时
- 每天都必须有可展示输出
- 优先打通最短闭环，再补增强项
- 每天预留 20% 时间给调试和修正

## Day 1：设计锁定与骨架搭建

### 目标

锁定技术方案、搭建前后端骨架、定义核心数据结构。

### 任务列表

1. 初始化前端项目与基础布局
   - 预计：2 小时
   - 输出：首页、策略实验室、交易复盘路由骨架
2. 初始化后端服务与基础路由
   - 预计：2 小时
   - 输出：FastAPI 项目骨架与健康检查接口
3. 实现策略 DSL schema 与校验器
   - 预计：3 小时
   - 输出：Pydantic schema / 校验逻辑
4. 建立数据库 schema 和本地开发配置
   - 预计：2 小时
   - 输出：建表 SQL、`.env.example`、数据库连接
5. 准备演示行情样例与交割单样例
   - 预计：2 小时
   - 输出：固定样例数据集

### 当日验收

- 前后端项目可启动
- 核心页面骨架可访问
- DSL schema 可独立校验示例 JSON

## Day 2：自然语言策略生成与指标系统

### 目标

完成“自然语言 → DSL → 指标配置”的主链路前半段。

### 任务列表

1. 接入 LLM 结构化输出生成策略
   - 预计：3 小时
   - 输出：`POST /strategies/generate`
2. 实现策略解释摘要与歧义提示
   - 预计：2 小时
   - 输出：生成结果中的 `human_summary` 和 `ambiguities`
3. 实现内置指标目录
   - 预计：2 小时
   - 输出：指标列表 API
4. 实现自定义指标表达式解析
   - 预计：4 小时
   - 输出：白名单表达式解析与 AST 校验
5. 完成策略实验室页面联调
   - 预计：3 小时
   - 输出：生成策略、查看规则、创建自定义指标

### 当日验收

- 输入自然语言后可得到结构化策略
- 合法自定义指标可创建，非法表达式会被拒绝

## Day 3：回测执行与结果页

### 目标

完成策略回测闭环和结果展示。

### 任务列表

1. 实现历史行情读取和标准化
   - 预计：2 小时
   - 输出：行情数据服务
2. 实现指标计算管线
   - 预计：3 小时
   - 输出：内置指标和自定义指标统一计算接口
3. 实现基础回测引擎
   - 预计：4 小时
   - 输出：买卖信号执行、收益统计、交易明细
4. 实现回测结果 API
   - 预计：2 小时
   - 输出：`POST /backtests/run`
5. 完成回测结果页图表展示
   - 预计：3 小时
   - 输出：收益曲线、回撤、交易表格

### 当日验收

- 能从策略实验室发起回测
- 能看到结果指标和交易明细

## Day 4：交割单复盘与建议生成

### 目标

完成“上传交割单 → 解析 → 特征分析 → 复盘建议”的闭环。

### 任务列表

1. 实现交割单上传与字段检测
   - 预计：2 小时
   - 输出：上传接口和字段识别
2. 实现字段映射确认与标准化解析
   - 预计：3 小时
   - 输出：标准化 trade records
3. 实现交易特征提取
   - 预计：3 小时
   - 输出：均线、量价、波动率等特征计算
4. 实现盈利 / 亏损交易对比分析
   - 预计：3 小时
   - 输出：结构化 winning / losing patterns
5. 接入 LLM 生成复盘总结与建议
   - 预计：2 小时
   - 输出：`POST /replays/analyze`
6. 完成复盘页联调
   - 预计：3 小时
   - 输出：上传、解析、复盘结果展示

### 当日验收

- 可上传样例交割单并生成结构化复盘结果
- 页面能展示成功 / 失败交易差异和建议

## Day 5：参数优化、规则回灌与演示收尾

### 目标

补齐优化闭环，完善演示路径和文档。

### 任务列表

1. 实现参数优化任务
   - 预计：3 小时
   - 输出：`POST /backtests/optimize`
2. 实现“建议转策略规则”
   - 预计：2 小时
   - 输出：`POST /replays/{id}/promote-rule`
3. 实现版本切换与结果对比
   - 预计：2 小时
   - 输出：版本对比界面
4. 完成核心手工测试和异常测试
   - 预计：3 小时
   - 输出：测试记录
5. 整理 README、演示脚本、复盘材料
   - 预计：2 小时
   - 输出：可演示版本与汇报材料

### 当日验收

- 能从复盘建议生成新策略版本并重跑回测
- 演示路径稳定，关键异常有兜底

## P0 / P1 划分

### P0

- 自然语言生成 DSL
- 自定义指标
- 单次回测
- 回测结果展示
- 交割单上传解析
- 结构化复盘分析

### P1

- 参数优化
- 建议转规则
- 版本对比

## 风险缓冲建议

- 如果 Day 2 的 DSL 生成不稳定，先用固定模板和少量受控策略描述保底
- 如果 Day 3 的回测引擎耗时过长，先限定单市场、单周期和固定样例数据
- 如果 Day 4 的复盘特征过多，先保留量价、均线、持仓时长三类特征
- 如果 Day 5 时间不足，优先保证复盘建议能展示，不强求完整自动回灌
