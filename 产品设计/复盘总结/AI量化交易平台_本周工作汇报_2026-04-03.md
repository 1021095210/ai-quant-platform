## 6. 核心架构与技术选型

- 前端：FastAPI 托管的多页面 `HTML + Vanilla JavaScript + CSS`
- 后端：`Python 3.11 + FastAPI + Uvicorn + SQLAlchemy`
- 数据层：
  - 业务数据：SQLite 起步，兼容 PostgreSQL
  - 市场缓存：独立 SQLite
  - 缓存与对象存储基线：Redis / MinIO
- AI 能力：
  - 金融导师：指标、交易知识、平台使用解释
  - 金融助手：多专家研究协作与结构化研究输出
- 部署：
  - Docker / Compose 基线
  - 外部依赖联调
  - 生产配置与 Cookie 安全项

---

## 7. 数据流与业务流

- 数据流：
  - 用户输入策略描述 -> 生成 DSL / Python 策略骨架 -> 保存项目版本
  - 发起回测 -> 冻结 `backtest_config` 与 `config_revision` -> 绑定 `data_snapshot_ref` -> 产出结果与对比
  - 上传交割单 / 截图 / 手动录入 -> 结构化交易记录 -> 复盘分析 -> 输出建议
- 业务流：
  - 首页进入 -> 登录 / 注册 -> 用户工作台
  - 从策略工坊生成策略 -> 保存项目 -> 去回测中心运行回测
  - 在交易复盘导入真实交易 -> 生成复盘总结 -> 追问金融导师 / 进入金融助手继续研究
