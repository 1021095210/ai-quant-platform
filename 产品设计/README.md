# 产品设计交付包说明

这套文件用于完成培训第一轮产品设计输出，建议按下面顺序使用：

1. 先阅读 [`培训首轮产品设计规划.md`](./培训首轮产品设计规划.md)，确认周一的交付目标、范围边界和默认决策。
2. 填写 [`选题说明模板.md`](./选题说明模板.md)，锁定一句话定义、目标用户、MVP 范围和不做清单。
3. 填写 [`设计文档模板.md`](./设计文档模板.md)，把需求、架构、数据流、模块和计划写完整。
4. 填写 [`验收演示脚本模板.md`](./验收演示脚本模板.md)，提前定义周五演示路径和通过标准。
5. 每天使用 [`每日站会与复盘模板.md`](./每日站会与复盘模板.md) 记录进度、风险和 AI 使用情况。
