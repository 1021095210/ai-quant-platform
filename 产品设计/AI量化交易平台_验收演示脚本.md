# AI 量化交易平台验收演示脚本

## 演示目标

- 本次要证明的核心价值：
  - 用户不写代码，也能把交易想法转成量化策略并验证
  - 用户上传历史交割单后，系统能自动发现交易模式问题并给出改进建议
- 目标用户是谁：
  - 有交易经验但缺少量化研发能力的个人交易者
- 演示时长上限：
  - 8 到 10 分钟

## 演示环境

- 访问方式：Web 页面，本地或演示服务器访问
- 账号或权限准备：单用户演示账号即可
- 测试数据准备：
  - 一份历史行情样例数据
  - 一份可解析的交割单样例文件
  - 一组预设自然语言策略描述
- 兜底方案：
  - 如果大数据集回测较慢，切换到预置中等规模样例数据

## 演示步骤

1. 打开首页
   - 操作：进入工作台，展示“策略实验室”和“交易复盘”两个入口
   - 预期结果：用户能直观看出平台既支持策略研究，也支持交易复盘

2. 自然语言生成策略
   - 操作：输入如下策略描述：
     - “当 5 日均线上穿 20 日均线，且 RSI 小于 70，且当前成交量大于过去 10 根均量的 1.2 倍时做多；止盈 8%，止损 3%。”
   - 预期结果：
     - 页面展示结构化策略 DSL
     - 页面展示策略解释说明
     - 用户能看到所用指标和参数

3. 展示自定义指标
   - 操作：新增自定义指标表达式 `volume / SMA(volume, 10)`
   - 预期结果：
     - 系统接受合法表达式
     - 该指标可以被加入策略条件

4. 执行回测
   - 操作：点击“开始回测”
   - 预期结果：
     - 返回收益曲线
     - 展示总收益、最大回撤、胜率、盈亏比、交易次数
     - 可查看单笔交易明细

5. 演示参数优化
   - 操作：将快线参数设为 `3-8`，慢线参数设为 `15-30` 运行优化
   - 预期结果：
     - 展示参数热图或参数列表
     - 显示最优参数组合及对应收益表现

6. 上传交割单并运行复盘
   - 操作：上传一份历史交割单样例，并选择重点分析维度为“量价关系 + 均线结构”
   - 预期结果：
     - 系统解析出交易记录
     - 页面展示盈利交易与亏损交易的关键差异
     - 页面输出“易亏损场景”和“可提升胜率的建议”

7. 从复盘建议生成新规则
   - 操作：选择一条建议，例如“避免在价格跌破 20 日均线且量能低于 10 日均量时入场”，点击“应用到策略”
   - 预期结果：
     - 平台生成新的策略过滤条件
     - 回到策略实验室并重新回测
     - 展示新旧版本结果对比

## 通过标准

- 平台能把自然语言转成结构化策略，而不是仅输出解释文本。
- 自定义指标不是写死配置，而是用户可新增并复用。
- 回测结果至少展示收益、胜率、回撤、交易明细。
- 交割单复盘不是纯文字点评，而是有结构化差异分析和明确建议。
- 复盘建议能反馈回策略研究链路，形成闭环。

## 风险预案

- 如果网络异常：
  - 切换到本地 mock LLM 输出或预置策略样例
- 如果部署环境不可用：
  - 使用本地 Docker 演示环境
- 如果 AI 接口超时：
  - 使用缓存好的策略 DSL 和复盘摘要
- 如果交割单解析失败：
  - 使用准备好的标准样例文件重新演示
