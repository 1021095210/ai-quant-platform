数据流转与业务流转（重点） 这是设计阶段最核⼼的部分。你需要把数据在系统中怎么流动、⽤户的业务操作怎么串联起来想清楚。
数据流转——回答”数据从哪来、经过什么处理、到哪去”： 示例（⼀个⽂档问答应⽤）： 数据⼊库流程： ⽤户上传⽂档(PDF/MD) → 后端接收并校验格式 → 按段落/语义分块 → 调⽤ Embedding API ⽣成向量 → 存⼊向量数据库(Chroma) + 原⽂存⼊ SQLite 问答流程： ⽤户输⼊问题 → 问题向量化 → 在向量库中检索 Top-5 相关⽚段 → 拼装系统提示词 + 检索⽚段 + ⽤户问题 → 调⽤ LLM API（流式） → 前端逐字展示回答 + 展示引⽤来源 业务流转——回答”⽤户从打开到完成⽬标，经过哪些步骤”： 示例（同上）： ⾸次使⽤：打开⻚⾯ → 上传⽂档 → 等待处理完成 → 看到"知识库就绪" ⽇常使⽤：打开⻚⾯ → 输⼊问题 → 看到流式回答和引⽤ → 点击引⽤查看原⽂ 管理操作：查看已上传⽂档列表 → 删除过期⽂档 → 重新上传更新版本
