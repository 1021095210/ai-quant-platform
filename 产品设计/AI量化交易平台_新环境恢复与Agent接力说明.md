## 四、新环境恢复步骤

如果你是新 Agent，请优先带用户执行以下步骤。

### 1. 检查关键目录

进入仓库后，先确认至少存在：

- `apps/`
- `infra/`
- `tests/`
- `tools/`
- `产品设计/`

### 2. 创建 Python 虚拟环境

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e apps/api
```

说明：

- 当前测试和服务启动最好优先使用仓库内 `.venv`
- 如果系统 `python3` 缺依赖，优先用 `.venv/bin/python`

### 3. 准备环境变量

```bash
cp .env.example .env
```

然后检查 `.env` 中是否需要补充：

- 数据库连接配置
- 行情数据源 Token
- LLM 相关配置
- 存储路径
- Redis / MinIO 配置

当前 LLM 相关配置已扩展为：

- `LLM_BASE_URL`
- `LLM_API_KEY`
- `LLM_MODEL_STRATEGY`
- `LLM_MODEL_SUMMARY`
- `LLM_MODEL_MENTOR`
- `LLM_DEEPSEEK_BASE_URL`
- `LLM_DEEPSEEK_API_KEY`
- `LLM_DEEPSEEK_MODEL`
- `LLM_VOLCENGINE_BASE_URL`
- `LLM_VOLCENGINE_API_KEY` 或 `ARK_API_KEY`
- `LLM_VOLCENGINE_MODEL` 或 `ARK_MODEL`

### 4. 先跑测试

推荐优先使用：


## 六、恢复后继续开发的优先顺序

如果环境已经恢复，请按下面的优先级继续，而不是重新发散。

### 第一优先级

- 做“实验 / 回测对比”层
- 支持同一策略不同回测配置、不同数据快照、不同版本的并排比较

### 第二优先级

- 为混合周期策略补“信号解释 / 时间对齐检查 / 未来函数风险提示”
- 让策略工坊到回测结果之间的语义断层继续缩小

### 第三优先级

- 推进更真实的多市场执行约束
- 继续补美股 / 加密货币 / 伦敦金的数据接入、日历、时区和成交规则

### 第四优先级

- 继续收敛工作台、回测中心、复盘页的空状态、错误态和平台文案
- 把当前临时隧道验证升级为更稳定的外部可访问部署方案

### 2026-04-02 细节更新

- 回测中心“当前回测详情”阅读顺序再次微调：
  - `核心指标 -> 回测曲线 -> 成交明细 -> 回测配置摘要 -> 执行可信度说明 -> 数据快照摘要 -> 策略 Python`
- 调整原因：
  - 成交明细对新手和半熟练用户更直观，放在曲线后面更容易把“净值变化”和“实际交易”对应起来。
- 本轮新增页面顺序断言测试，避免后续又把“成交明细”塞回过深位置。
- 外部访问隧道已续接，需要用最新临时链接验证，不要默认旧链接仍然可用。
- 额外数据源状态：
  - 已试连 `Tushare`，当前提供的 token 调用 `trade_cal` 返回 `40203` 无接口权限，暂未接入现有数据链路。
- 回测历史区新增两项交互基线：
  - 历史记录展示高度会跟随左侧“运行新回测”面板，自身内容超出后才滚动。
  - 历史记录支持删除，但仅允许删除已结束的回测；运行中的回测会返回 `STATE_CONFLICT`。
- 策略工坊顶部状态区已收敛：
  - 不再显示“当前标题 / 未命名”。
  - 顶部改为可直接编辑的“策略名称”输入框，页面内不再保留重复的第二个标题输入入口。
- 策略工坊版本展示进一步调整：
  - 用户可直接编辑“版本标签”，保存后会随策略项目一起落库。
  - 系统内部 `version_id` 仍保留，但只作为系统版本 ID 展示，不再作为用户主操作入口。
- 进度引导按钮已开始按逻辑亮起：
  - 策略工坊中，`保存项目` 和 `去回测中心` 默认禁用；成功生成 Python 策略后会切到主按钮态。
  - 指标设置中，`保存到自定义指标库` 默认禁用；成功生成自定义指标后会切到主按钮态。
- 同类交互已继续扩展：
  - 交易复盘中，`上传并解析 / 登记截图并生成记录 / 提交手动记录` 会先按当前来源数据是否齐备决定是否点亮；解析完成后才点亮 `运行 AI 复盘`。
  - 规则模块中，`保存术语解释` 只有在术语和含义填写完整后才点亮；`保存默认规则` 只有在默认规则被实际编辑后才点亮。
