用户工作台

策略工坊

输入自然语言，生成 Python 策略和机器可执行的规则规格。

Step 3

指标设置

查看传统指标计算代码，生成并保存自定义指标，供策略随时调用。

Step 4

规则模块

查看多市场默认研究规则，并补充 AI 要理解的交易术语与市场约束。

Step 5

回测中心

按股票 / ETF 日线运行回测，查看每次结果、数据来源和交易明细。

Step 6

交易复盘

上传历史交割单，分析成功与失败模式，并把建议回灌到策略。
